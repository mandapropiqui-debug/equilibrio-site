# Farmácia Equilíbrio — site

Vitrine + pedido por WhatsApp da Farmácia Equilíbrio (Teresina/PI).

- Um único `index.html`, responsivo: abre a versão mobile no celular e a desktop no computador, no mesmo link.
- Carrinho de pedido com manipulados, escolha da unidade (sugere a mais próxima) e envio para o WhatsApp da unidade.
- Sem build, sem dependências: fontes, logo e fotos estão embutidos no arquivo.

Publicação: GitHub Pages (branch `main`, pasta raiz).
